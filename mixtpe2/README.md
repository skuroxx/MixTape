# MixTape

- `client/`  readable browser source (app.js, style.css, amlyrics.*). Edit these. They are never served.
- `public/`  generated by `scripts/build-client.mjs` (minified + mangled). Don't edit; rebuilt by `npm run dev` / `npm run build`.
- `app/api`, `lib/`  server code (runs on the server, never sent to the browser).
- `dev-demo/`  lyrics demo page, not deployed.

    npm install
    npm run dev      # rebuilds client assets, then starts Next
    npm run build    # production build (also strips console.* from the client bundle)
